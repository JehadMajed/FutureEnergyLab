# Contributing

This repository hosts the Future Energy Lab's projects at Prince Sattam bin Abdulaziz
University. Contributions from lab members, students, and collaborators are welcome.

## Where to work

Each project is self-contained under its own top-level folder (`ArcFault/`, `DataSetup/`,
`Digital Twin/`, `MicroGrid/`, `Smart Meter/`, `Topology/`, ...) with its own `README.md`.
Start there for that project's setup, structure, and conventions before making changes.

## Making a change

1. Create a branch off `main` (e.g. `feature/arc-fault-images`, `fix/microgrid-sizing-numbers`).
2. Keep changes scoped to one project folder where possible — it makes review easier.
3. If you're updating a result, number, or claim, cite where it came from (a script, a
   dataset, a report) so it can be verified later.
4. Open a pull request describing what changed and why.

## Reporting issues

Open a GitHub issue for bugs, broken links, or outdated information. For security
vulnerabilities in the Digital Twin project specifically, see
[`Digital Twin/SECURITY.md`](Digital%20Twin/SECURITY.md) instead of a public issue.

## Adding a new project

New project folders are welcome — add a `README.md` inside it, then add a row to the
"Current Projects & Code" table and the repository structure tree in the root
[`README.md`](README.md).
