# Low-Voltage Distribution Topology Inference

Research on inferring low-voltage (LV) distribution network topology — part of the lab's
broader work on **management and operation of distribution networks**: topology inference,
state estimation, and operational decision support for low- and medium-voltage networks,
validated against field measurements.

## Approach

The method infers LV distribution topology from **trench footprints**, using a deep-learning
framework validated with **infrared thermal imaging**.
